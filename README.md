# Machine-checked fragments of a base-10 prime pattern

**Elizabeth Johnson (@Ellyrox110) and Jeromie Beasley.** This is built on Elizabeth Johnson's framework,
*EJ's Alternate Base Prime Number Pattern and the Twin Prime Counterflow Model*,
DOI [10.5281/zenodo.23378596](https://doi.org/10.5281/zenodo.23378596). The framework is hers
alone. The results in this repository are joint.

**Attribution note.** A related document, *Advanced Color Theory in Relations to Primes* (Elizabeth Johnson and Shaun Neer, October 2026), lists a second author. The attribution of the colour scheme and its mixing rules, credited here to Elizabeth Johnson, is still being verified with the authors, and will be corrected in a later revision if needed.

* **Read the paper:** `01-report/report.pdf`, or `01-report/report.html` in a browser.
* **The proofs are re-checked automatically:** every push runs the "Lean proofs" check on
  GitHub (see the Actions tab), so a green tick means everything built with no `sorry`. To build
  them yourself, see `07-lean-package/README.md`.
* **Citing:** use the "Cite this repository" button (from `CITATION.cff`).

### 01-report
* `report.pdf` — the paper. Thirteen pages. Both authors on it.
* `report.tex` — source; `latexmk -pdf` in this directory to rebuild.
* `figures/` — four vector figures, regenerated by `04-verification/make_figs.py` (it also draws an old residue-order wheel, `fig4_wheel.pdf`, no longer used; the report draws the wheel in TikZ).

### 02-lean
* `Census.lean` — the census on words for all $n$, realised ⇒ admissible, the seed
  counterexample, numeric corollaries, `#eval` of the counter.
* `EJPrime.lean` — twin-start digits, digit exclusivity, junction uniqueness, the equilibrium
  obstruction stated on primes.
* `Wheel.lean` — the wheel at $W=10$ (coordinates, orbits, rotation by units, complement, layer
  swap, twins avoid the grey hue) and colour at scale (the 100- and 125-wheels over the 10-wheel).
* `README.md` — **the authorship split**, and the posting note.

All three files are built as a Lake package (see `07-lean-package/`). Expected output and axiom footprints are in
`05-handoff/manifest.json`.

### 04-verification
The scripts. `verify_all.py` and `final_check.py` re-derive the claims and print PASS/FAIL;
`make_figs.py` redraws `01-report/figures/`; the rest are the individual experiments.

### 05-handoff
* `HANDOFF.md` — the publication runbook, with integrity and Lean gates.
* `REVIEW.md` — **the reviewer brief**: eight claims, the non-claims, the known exceptions, the
  withdrawn statements, and three specific things worth attacking.
* `PUBLISH.md` — the git/connector route.
* `manifest.json` — revision, file list, sizes, sha256, expected Lean output.
* `push.sh` — run from anywhere; runs `check_pack.py`, runs Lean if `LEAN_PROJECT` is set, then commits and pushes the whole pack.
* `check_pack.py` — gate 1a: sha256 of every file against `manifest.json`, and a scan for withdrawn statements.

### 06-data
Small tables only. The full datasets (385 676 segments, 5 000 000 primes) are regenerated by
`04-verification/build_dataset.py`-style scripts from a sieve; they are not shipped here.

## The claim, in one sentence

Admissible residue words of length $n$ over $\{0,2,4,6,8\}$ number $3^{n+1}-2^{n+1}$; every word the
twin gaps actually produce is admissible; and that is the whole of the deductive content — the
converse, that every admissible word occurs, is a prime-tuples statement and is **not** proved.
